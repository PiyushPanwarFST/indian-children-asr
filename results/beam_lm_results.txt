Key findings:
  1. Beam+LM improves ALL branches significantly (1.9% to 6.1% absolute)
  2. Semantic branch alone (12.09%) beats the combined branch (12.65%)
     because the semantic encoder was further improved with CTC-only
     unfrozen training (Exp 3), while combined branch still uses the
     older semantic MSE encoder
  3. ALL branches with beam+LM beat the fine-tuned Whisper baseline (14.30%)
  4. Combined V2 (training now) uses the improved semantic encoder —
     expected to achieve 10-11% WER with beam+LM
